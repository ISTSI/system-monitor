# Normalized two-system collision fixtures

`events.json` contains four synthetic normalized records, two per system. It deliberately repeats event/process/source IDs and timestamps across projects, with ALPHA/BETA message markers. Full identity is `(project_id,event_id)`; these are not additional source-byte oracles for the original physical log files. `scenarios.json` lists future application tests, not execution results. All original v2 log fixture files remain unchanged.
